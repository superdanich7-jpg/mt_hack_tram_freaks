# SUBMISSION.md — формат сабмита

## Формат
route;date;hour;prediction
1;2025-11-01;0;349
1;2025-11-01;1;349
...

text

- Разделитель: `;`.
- Кодировка: UTF-8.
- Заголовок обязателен.
- Колонки строго: `route;date;hour;prediction`.

## Правила

- `route` — int из `[1,5,7,11,12,17,25,26,28,50]`.
- `date` — формат **как в `test_submission.csv`**.
  В README написано `YYYY-MM-DD`, в реальном файле может быть `DD.MM.YYYY`.
  Не угадывать: открыть шаблон и смотреть.
- `hour` — 0…23.
- `prediction` — целое ≥ 0.

## Сетка

Полная: **10 маршрутов × 61 день × 24 часа = 14 640 строк**.

## route=5

Обучать нельзя. В сабмите — **нули**. Это даст потерю ~0.006 по метрике,
не критично.
