## Горизонт прогноза

- Обучаемся: 2025-01-01 … 2025-10-31.
- Предсказываем: 2025-11-01 … 2025-12-31.
- 9 маршрутов × 61 день × 24 часа = **13 176 строк** для реальных
  маршрутов. Плюс route=5 нулями → **14 640** всего.

## Метрика
WAPE = Σ|y − ŷ| / Σy
WAPE-score = max(0, 1 − WAPE)

text

- Устойчива к нулям и разбросу объёмов.
- Целевой ориентир: **> 0.48** (baseline), стремимся к 0.85+.
- По Q&A известно, что при обнулении route=5 максимальный потолок
  ≈ **0.9935**.

## Схема валидации

Основная:

- Train: 2025-01-01 … 2025-09-30.
- Valid: 2025-10-01 … 2025-10-31.

Альтернативная (для устойчивости):

- Несколько фолдов: август, сентябрь, октябрь. Rolling-origin.

Baseline для сравнения:

- Наивный: медиана/среднее по `route + hour + dayofweek` за последние
  4–8 недель относительно даты прогноза.
- Если модель не бьёт этот baseline — что-то не так.

## Что нельзя

- Обучать на route=5.
- Использовать ground truth ноября–декабря (его нет).
- Подглядывать в будущее при построении агрегатов (leakage).
- Использовать `input_date_time` из сырых файлов — битый.

## Что можно

- Внешние данные: погода, праздники, расписания из открытых источников,
  новости Дептранса, опубликованные после 31.10.2025 (Q&A разрешает).
- Любые ML-модели: gradient boosting, linear, ARIMA, Prophet,
  нейронки — без ограничений.
- Ансамбли, стекинг, blending.

## Итоговое решение

- Обучаем на **всей** истории: 2025-01-01 … 2025-10-31.
- Предсказываем ноябрь–декабрь.
- Округляем до целого, clip ≥ 0.
- route=5 → 0.
