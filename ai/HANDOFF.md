# HANDOFF.md — передача команде

## Что команда должна получить от капитана

1. `submissions/submission.csv` — финальный сабмит.
2. `submissions/forecast.csv` — данные для сервиса.
3. `README_ML.md` — инструкция.
4. `reports/validation.md` — метрики, чтобы защищать решение.
5. `api_spec.md` — контракт API.
6. Модель в `models/`.
7. Репозиторий на gitverse с чистым кодом.

## Что делает backend

- Поднимает FastAPI по `api_spec.md`.
- Читает `forecast.csv`.
- Делает Docker.
- Добавляет базовую авторизацию.
- Отдаёт ссылку и логин/пароль жюри.

## Что делает frontend

- Дашборд по `WEB_SERVICE.md`.
- Подключён к API backend'а.
- Тёмная тема, сплит, фильтры, карта (если успеет).

## Что делает non-coder

- Собирает презентацию.
- Проверяет чеклисты.
- Пишет тексты.
- Делает скриншоты.
- Готовит логины/пароли.
- Следит за дедлайном 27.09.2025 23:59 МСК.

## Что должно быть в презентации

- Проблема и задача.
- Данные.
- Методы и подходы.
- Технологический стек.
- Результаты и метрики.
- Демо сервиса.
- Что можно улучшить дальше.

## Чеклист сдачи

- [ ] CSV загружен в «Data Science».
- [ ] Форма «Загрузка решения» заполнена.
- [ ] Все члены подтвердили участие на платформе.
- [ ] Репозиторий на gitverse открыт для жюри.
- [ ] Логины/пароли переданы.
- [ ] Презентация готова.
- [ ] Docker-образ собирается и запускается.
