# DATA.md — данные

## Что есть в архиве

| Файл / папка | Что это |
|---|---|
| `train.csv` | Сырые валидации, январь–август 2025 (~7 ГБ) |
| `test.csv` | Сырые валидации, сентябрь–октябрь 2025 (~2 ГБ) |

| `labels/labels_day_test.csv` | Готовая почасовая разметка test |

| `README.md` | Официальное описание |

## Главное правило

**Обучаемся на `labels/*`, а не на сырых `train.csv`/`test.csv`.**
Сырые файлы — 2–7 ГБ, парсить их в лоб больно. `labels` уже агрегированы
по `route;date;hour;boardings`.

## Формат labels
route;date;hour;boardings
1;2025-09-01;4;9
1;2025-09-01;5;143
...

text

- `route` — int, номер маршрута.
- `date` — `YYYY-MM-DD`.
- `hour` — 0…23.
- `boardings` — int ≥ 0, число успешных валидаций.

## Маршруты

10 маршрутов: `1, 5, 7, 11, 12, 17, 25, 26, 28, 50`.

**Маршрут 5 — битый.** В labels его нет. В сабмите — нули.
Реально работаем с 9 маршрутами.

## Полная сетка

Ключи: `route × date × hour`. Пропуски `boardings = 0`.

Для обучения (январь–октябрь):

- 9 маршрутов × ~304 дня × 24 часа ≈ 65 664 строк (может отличаться).
- Строим сетку сами, чтобы не терять нули.

## Временные границы

| Выборка | Период |
|---|---|
| train | 2025-01-01 … 2025-08-31 |
| test | 2025-09-01 … 2025-10-31 |
| прогноз | 2025-11-01 … 2025-12-31 |

## Особенности

- Ночные часы 2–4 часто пустые или технологические → возможно
  отфильтровать. Решать по валидации.
- Часть дней может иметь аномальные провалы (ремонты, отключения
  валидаторов). Их стоит уметь восстанавливать по аналогам.
- Суточный «хвост» валидаций может попадать в следующий день — при
  работе с сырыми CSV фильтруй строго по `tran_date_time`.
- `place_id` — это депо/площадка, **не остановка**.

## Справочники (spravochniki)

`Хакатон_справочники_трамвай_10_маршрутов.xlsx` содержит листы:

- `Маршруты GTFS_ROUTES` — реестр маршрутов.
- `Остановки GTFS_STOPS` — остановки с координатами.
- `Порядок_остановок GTFS_TRIPS_ST` — порядок остановок по рейсам.
- `Наряд` — выходы ТС.
- `Расписание` — расписание рейсов.
- `Порядок_с_координатами` — порядок остановок + координаты.

Использовать для карты в веб-сервисе. Для основной метрики — не обязательно.
